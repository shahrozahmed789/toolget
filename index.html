Settings & Help

How this private prototype works and what it needs to become a live research product.

CSV workflows

Import common CSVs and export module data for analysis.

Enable real Etsy search (optional, no third-party subscription)

To enable live Etsy listing analysis in the deployed Netlify version, first obtain Etsy’s express written authorization for analytics use, then set ETSY_ANALYTICS_AUTHORIZED=true and ETSY_API_KEY in Netlify. Keep API credentials server-side; never paste them into the browser or chat. The app will then call its Netlify Function to search Etsy listings.

Pinterest currently has no general keyword-to-public-Pins search flow wired into this prototype. Its API can provide your authorized account’s Pins/analytics and permitted trend data depending on app permissions, but it does not allow scraping or unauthorized competitor benchmark extraction.

Not automatically available in this version

Etsy live listing search and shop analytics are blocked by default because Etsy API Terms restrict analytics collection unless expressly authorized in writing. If Etsy grants written authorization, set the explicit authorization gate and API key in Netlify. Otherwise use Etsy search links and manual/CSV imports. Pinterest live top-growing trends require approved Pinterest Trends API access and a token. The general Pinterest keyword-to-all-Pins thumbnail search, competitor saves/repins extraction, and automatic Pinterest competitor benchmarking are not connected.

CPC, broad keyword search volume, and competition scores stay blank unless your permitted data source supplies them. The app does not scrape private pages, bypass logins, or invent metrics.
